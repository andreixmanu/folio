# Folio

Personal investment portfolio app (Android + web), built with Expo SDK 58, Expo Router and TypeScript (strict).

**Phase 1:** UI foundations with typed mock IBKR stocks and live read-only Tangem crypto balances via the Cloudflare Worker. Later phases connect IBKR Flex Query and RSS feeds.

## Scripts

```bash
npm start            # expo start (Expo Go)
npm run web          # web dev server
npm test             # jest-expo + React Native Testing Library
npm run typecheck    # tsc --noEmit
npm run lint         # expo lint
npm run doctor       # expo-doctor
npx expo export --platform web
```

## Asset icons

Logos are bundled as 128 px circular PNGs in `assets/asset-icons/` (offline, Expo Go friendly),
generated by `scripts/asset-icons` (`npm install && npm run build`), which also writes
`src/components/ui/asset-icons.generated.ts` and `assets/asset-icons/SOURCES.md` (per-icon source
and licence). `<AssetAvatar>` uses bundled icon → worker `/logo/:symbol` (stocks only) → initials.

## Structure

```
src/
  app/                 Expo Router routes: (tabs)/index (Portfolio), news, assistant, settings
  theme/               tokens: colors, spacing, radii, typography, motion, elevation + ThemeProvider
  components/ui/       IslandCard, ListRow, ChangeChip, SegmentedControl, FilterChips, AnimatedNumber, Screen…
  components/navigation/ FloatingTabBar (pill, detached, animated indicator)
  components/charts/   ValueChart (area line), AllocationDonut
  features/            screen sections (portfolio hero, allocation, sources, holdings, news cards)
  services/            typed domain + data sources (mock now) + React Query hooks
  store/               Zustand UI state (range, filters, privacy mode, theme)
  lib/                 formatting, haptics (no-op on web), PRNG
```

Swap data sources in `src/services/sources.ts`; hooks and screens stay unchanged.

## Wallets (Tangem)

Crypto holdings come from `GET /wallets` on the Worker (Bitcoin + Ethereum + USDC/USDT). The app sends `X-Folio-Token` and never displays receive addresses. Stocks stay on the IBKR mock. Pull-to-refresh on Portafoglio reloads wallets and quotes.

## Assistente

The Assistente tab is a markets-only chat. The app streams `POST /chat` on the Folio Worker
(`text/event-stream`: `delta`, `sources`, `error`, `done`). The Worker calls xAI; the app never
holds an xAI token. It sends `X-Folio-Token` and, when a portfolio is loaded, a compact snapshot
(weights by holding, allocation by class). With **Nascondi saldi** on, quantities and euro amounts
are left out of that payload. The Worker currently requires those numbers, so a hidden-balance
turn is rejected as `invalid_body` until the check allows a weights-only portfolio.

- `EXPO_PUBLIC_API_URL` — Worker base URL, or the Expo `/api` proxy in dev (see `.env.example`).
- `EXPO_PUBLIC_CHAT_TOKEN` — must match `APP_CHAT_TOKEN` in `worker/.dev.vars` (`/chat` and `/wallets`).

```bash
cd worker
cp .dev.vars.example .dev.vars   # set APP_CHAT_TOKEN
npm run login:xai                # device flow; prints a verification URL, then stores a refresh token locally
```

If the assistant replies that login is required, run `npm run login:xai` again from `worker/`.
In dev, Metro proxies `/api/*` to the Worker and flushes `text/event-stream` without buffering.
